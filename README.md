This project is a Hotel Management System application developed using Java Core, Swing, JDBC, and MySQL. The application supports essential hotel operations such as customer registration, room management, reservation tracking, employee management, and reporting. With its Swing-based user interface, it provides a user-friendly desktop experience, while JDBC ensures that data is securely stored in the MySQL database. This project was developed to gain practical experience in desktop application development with Java as well as database integration.
